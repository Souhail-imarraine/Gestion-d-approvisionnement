## 🎯 Introduction

**Spring Security** est le framework de sécurité standard pour les applications Java et Spring Boot. Cette roadmap est conçue pour vous aider à comprendre en profondeur les concepts de sécurité, pas seulement à écrire du code.

### Vous apprendrez :
- ✅ **POURQUOI** chaque concept existe
- ✅ **COMMENT** il fonctionne en interne
- ✅ **QUAND** l'utiliser dans des projets réels

## 📚 Niveaux d'apprentissage

### 🟢 [Niveau 1 : Débutant](./01-BEGINNER.md)
Apprenez les fondamentaux de la sécurité applicative et Spring Security.

**Concepts** : Authentication vs Authorization, HTTP Security, Sessions, Cookies

**Projet** : API REST simple avec login et routes protégées

---

### 🟡 [Niveau 2 : Intermédiaire](./02-INTERMEDIATE.md)
Maîtrisez le cœur de Spring Security et la gestion des utilisateurs.

**Concepts** : Security Filter Chain, UserDetailsService, BCrypt

**Projet** : Système de gestion utilisateurs avec rôles (ADMIN/USER)

---

### 🟠 [Niveau 3 : Avancé](./03-ADVANCED.md)
Sécurisez vos APIs avec JWT et l'authentification stateless.

**Concepts** : JWT, Access/Refresh Tokens, API Security

**Projet** : API REST sécurisée avec JWT (login, refresh, logout)

---

### 🔴 [Niveau 4 : Expert](./04-EXPERT.md)
Implémentez des solutions de sécurité de niveau entreprise.

**Concepts** : OAuth2, OpenID Connect, SSO, Microservices Security

**Projet** : Backend Enterprise avec OAuth2 & JWT
